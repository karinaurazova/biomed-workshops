# Мастер-классы по матмоделированию для школьников

Интерактивные мастер-классы по математическому моделированию в биомедицине для 8–11 классов.

## Локальный запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не нужны. Для работы через локальный HTTP запустите `python3 -m http.server 8000` из папки проекта.

## Структура

- `workshops.js` — названия, задачи, подсказки, разборы, пометки для ведущего, ссылки.
- `models.js` — расчёты учебных моделей, параметры и отрисовка графиков.
- `vision.js` — веса небольшой нейросети. Она обучена на отдельно сгенерированных масках, получает яркость пикселя и среднюю яркость окрестностей 3×3 и 5×5.
- `app.js` — каталог, маршруты, привязка параметров и вывод результатов.
- `styles.css` — стили страниц и адаптивная раскладка.

Чтобы завести новый мастер-класс, добавьте запись с уникальным `id` в `workshops.js`. Укажите ключ `model` или список `stations`. Запись появится в каталоге и будет доступна по ссылке `#workshop/ваш-id`. Для новой модели добавьте параметры, функцию отрисовки и показания в `models.js`.

## GitHub Pages

Опубликуйте корневую папку ветки `main` через Settings → Pages → Deploy from a branch. Файл `.nojekyll` обслуживает исходные файлы без обработки Jekyll. Все пути относительные, включая ссылки на отдельные занятия.

Данные и численные пределы синтетические. Материалы предназначены для школьных экспериментов с упрощёнными моделями.
